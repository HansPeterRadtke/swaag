## Fixes from the full pass

- Added durable unresolved-question projection and explicit evidence-backed resolution, legacy checkpoint migration, context/recovery integration, bounded capacity, and worker/AG-UI lifecycle events.
- Added a bounded durable queue for explicitly authorized unstarted plans. It defaults to finish-only, defers to foreground work, holds revised plans, records authorization provenance, and recovers dispatch commits after restart.
- Fixed Infra model launcher occupied-port behavior, context/recurrent and split-shard memory admission, symlink checking, invalid-policy refusal, and misleading appendix documentation. Eleven isolated safety tests pass; the loaded production model was not restarted.

- Fixed SSE character decoding: UTF-8 model output no longer inherits HTTP text defaults that corrupt accented, CJK or emoji characters.
- Fixed database connection lifetime across all ten SQLite stores, including rollback and failed setup. Owned connections close deterministically instead of exhausting file handles before garbage collection.
- Added atomic admission limits for worker, session-control, communication and model-request queues; released completed futures; bounded token-count memo and record/replay cache data/lock files. Cache pressure preserves committed replay evidence.

Those recorded answers exposed a distinct transport defect: Requests inferred Latin-1 for `text/event-stream`, corrupting non-ASCII UTF-8. The preserved independent reproduction is `unicode-stream-before.json`. SSE is UTF-8 by [the HTML event-stream specification](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation). The client now fixes its incremental decoder before reading. Three new cases split every byte across chunks and cover absent/Latin-1/UTF-8 inferred encodings; streaming/cache regression tests pass 22/22. A fixed-grammar transport-only probe of the actual running Qwen endpoint preserved `Grüße — 東京 🚀` exactly in 3.29 seconds (`utf8-live.json`); this is not a semantic or latency benchmark.
