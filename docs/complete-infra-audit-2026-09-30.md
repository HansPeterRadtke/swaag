# Complete Infra applicability audit — 2026-09-30

This supersedes the earlier selected-guideline review for reading coverage. It does not certify one hundred percent compliance. Implementation, mechanical validation, live model behavior, and external/client acceptance are separate claims.

All 569 inventoried Infra files are accounted for: 548 authored or byte-identical preserved guidance/implementation files were read; 21 credential, vendor, catalog, and binary files received explicitly recorded inspections. Credentials were not disclosed. Vendor bundles were fingerprinted and inspected for local license/version metadata; they were not semantically audited in full. All 139 original recordings and their verbatim appendix copies were covered.

The immutable reading snapshot, page acknowledgements, special inspection methods, exact appendix-integrity record, and machine-readable requirement mapping are under `/data/var/swaag-benchmarks/complete-infra-audit-20260930`. The source snapshot contains credentials and remains access-restricted; it is not published in this repository.

## Fixes from the full pass

- Added durable unresolved-question projection and explicit evidence-backed resolution, legacy checkpoint migration, context/recovery integration, bounded capacity, and worker/AG-UI lifecycle events.
- Added a bounded durable queue for explicitly authorized unstarted plans. It defaults to finish-only, defers to foreground work, holds revised plans, records authorization provenance, and recovers dispatch commits after restart.
- Fixed Infra model launcher occupied-port behavior, context/recurrent and split-shard memory admission, symlink checking, invalid-policy refusal, and misleading appendix documentation. Eleven isolated safety tests pass; the loaded production model was not restarted.

- Fixed SSE character decoding: UTF-8 model output no longer inherits HTTP text defaults that corrupt accented, CJK or emoji characters.
- Fixed database connection lifetime across all ten SQLite stores, including rollback and failed setup. Owned connections close deterministically instead of exhausting file handles before garbage collection.
- Added atomic admission limits for worker, session-control, communication and model-request queues; released completed futures; bounded token-count memo and record/replay cache data/lock files. Cache pressure preserves committed replay evidence.

## Acceptance state

The final local release is installed on Jetson. Implementation commit `6ce2fdb73cbd659bcf466ec571d667bd7e8e97fd` is pushed; Infra safety commit `030f20c` is pushed. The full frozen-source gate passed **999 tests**, with **three optional external-tool integration tests skipped**, **zero failures**, in **1,220.58 seconds** under the normal 1,024-descriptor limit. All 325 frozen source/test/script/build files remained unchanged.

The installed wheel is `release-final/wheel/swaag-0.1.0-py3-none-any.whl` under the evidence root, SHA-256 `ec1decd770e543592694f80b26c0a59747e133844a43a5a1a34153ebc2a61adf`. All 184 package files match tested source exactly. Production verification passes **16/16**; the live JSON-line backlog/migration/service-preservation probe passes **6/6**. The communication service is active with zero automatic restarts. Its backlog is empty and mode is `finish_only`; automatic dispatch is disabled. The model and Collector kept their existing processes. The previous package and all ten SQLite databases are preserved in an access-restricted deployment backup.

Focused gates passed 89 database/lifecycle/history/scheduler/queue tests, 62 capacity/cache/configuration tests and 22 streaming/cache tests. These are separate overlapping runs, not an additive unique-test count. Infra model-start safety tests pass 11/11. The installed connection-pressure probe retained 400 connection references with cyclic garbage collection disabled: all 400 writes survived and open descriptors stayed at four. The unrelated Infra video-library suite could not import Starlette in the available environments; it was not represented as passing and its service/dependencies were not altered.

Real Qwen question lifecycle passed **7/7 assertions** in 2,021.09 seconds: the recorded answer resolved only the destination question as Oslo, the separate unanswered accent question and its provisional assumption survived, the final response matched exactly, independent completion approved it, and history replay matched active state. The first zero word-count constraint was rejected before any tool execution and recovered through normal validation feedback. Both instruction-category holdouts passed **6/6 assertions each**: programming in 1,843.32 seconds and research in 2,337.32 seconds, with correct category selection, unrelated-category exclusion and unchanged stores. The research case recovered from an invalid empty terminal response. No held-out answer was used to tune these prompts.

Inspection of those immutable outputs exposed non-ASCII transport corruption. The before-fix reproduction is retained in `unicode-stream-before.json`. SSE is UTF-8 by [the HTML event-stream specification](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation); the client now fixes its incremental decoder before reading. Three regression cases cover absent/Latin-1/UTF-8 inferred encodings with every byte split across chunks. An actual-endpoint fixed-grammar transport probe preserved `Grüße — 東京 🚀` exactly in 3.29 seconds (`utf8-live.json`). This is transport evidence, not a semantic or representative-latency benchmark. Earlier stored outputs/cassettes remain unchanged. The question/category live jobs preceded the final connection/decoding fixes; question, tool, runtime and prompt semantics stayed unchanged, and the final package has separate persistence, transport and full-suite evidence.

Failed and superseded baselines remain retained. `full-suite-superseded.log` ended with 211 failures, 756 passes and three skips after old imported configuration code encountered newly edited defaults; it was not a valid frozen release gate. `full-suite-connection-leak.log` found the real SQLite handle-lifetime defect plus a stale schema assertion: 979 passed, three skipped, two failed and two setup errors. All ten store factories now close owned connections on success, rollback and failed setup, and archive readers close on failure. Thirteen regressions cover those contracts and migration preservation. `full-suite-before-utf8-correction.log` was intentionally interrupted after 741 passes and three skips, with no failures, to include the independently reproduced decoding fix. Earlier candidate wheels are superseded and were never installed in production during this full audit.

The earlier production Pipe run, nine-case small-context matrix, 27-case scheduler matrix, workspace/log verifiers and 941-test suite remain historical evidence for the previous release. They are not relabeled as fresh browser or frontend acceptance for this code. The current model listener remains on all interfaces; the communication daemon is loopback-only. No external exposure change was made. All eleven unrelated dirty Infra paths and the original SWAAG stash are preserved; continuously generated LLM report contents changed independently.

Open acceptance boundaries remain: cold interactive latency, broader autonomous question/authorization and authority-conflict trajectories, cross-model/long-horizon semantic evaluation, actual browser rendering/uploads/downloads, protected external MCP OAuth/CIMD/TLS and deployment-specific A2A OAuth/OIDC/gRPC. Optional embedding/callback lifetime-pressure acceptance also remains open, and proactive idea generation is disabled. This release closes the documented concrete implementation defects and its local validation gates; it does not establish one hundred percent compliance across those unaccepted deployments and behaviors.
