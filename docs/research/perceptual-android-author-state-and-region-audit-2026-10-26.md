## Hard genuine author-clean controls, SAME app and dimensions but different activity

The pinned source [RotBench author-released original images](https://huggingface.co/datasets/ImDim/RotBench) contain 170 author-approved *right* portrait/landscape screen pairs. Every one of their 340 PNGs was located locally and **reverified by SHA-256** against the preceding two frozen original-source extraction manifests. No discrepancy was found and no new image was downloaded. Of the 170 right cases, **137** had a different, author-approved activity screen from the *same package, with the same native dimensions and orientation*. The protocol froze up to three deterministically hash-ranked alternatives, producing **352** clean-vs-clean image-pair comparisons across **28 Android apps** and 704 orientation-level comparisons. The frozen manifest SHA-256 is `ede80b2b8d568887bcb926c7d738f676e54b2c2b76ee9146930ccaf0a4124659`. These are correlated and not 352 independent clean applications.

| Pre-existing frozen pixel rule, same actual native images and comparison budget | Author-clean screenshot pairs falsely labelled changed/defective if wrong activity is treated as approved reference | Correct interpretation |
|---|---:|---|
| Local changed-pixel area >0.05% at max channel delta >=24 | **352/352** | Unverified semantic GUI defect, REVIEW because activity ID mismatched |
| Global pixel mean absolute change >1.5 | **351/352** | Likewise REVIEW; same exact native pixels and reference |
| Any pixel changed | **352/352** | Detects different screens, not a quality failure |
| Exact original screenshot as its *own* reference | **0/352** | PASS for that single immutable screenshot-equality property only |
| Version/activity-aware source binding | **352/352 REVIEW** | No auto-FAIL and no universal GUI PASS |

The actual original screenshots in every comparison were author-accepted correct GUI states. The alternate activity may have different content while remaining completely valid; a pixel difference is not a GUI clipping, contrast or overlap defect. Same-app and same-orientation do not establish equivalence to the same activity/state. **This is deliberately an invalid-reference stress test**, not a fair production false-positive estimate for a correctly bound immutable regression screenshot. Unlike the prior other-app and wrong-orientation shams, it isolates missing *activity/state identity* while holding app, viewport and version constant. A separate null always-accept classifier would have zero alerts here but no ability to catch an actual defect.

## Independent released source annotation cross-check of previous false negatives

A separately published `bug_classification_and_localization/test.json` file at the same exact RotBench revision has SHA-256 `20205c875b10dba7501fd5b4304d2dfd3ceb26ac840f3fde08160a4156faf422`. Matching the exact *mutated PNG path* (not numeric case IDs) found **72** original prior detection mutations with a source-author region annotation; **70** had their original right reference PNG and **2** could not be scored because original clean source images were absent. The previous prediction SHA receipts were validated before this posthoc comparison; no prior threshold was changed or prior denied operation retried.

Of the 70 evaluable mutations, **63 were detected and 7 missed** with the frozen changed-area rule. All seven true changed-pixel masks were below the 0.05%-of-screen threshold, despite a concrete author-injected mutation. In **8 of the 70** available cases the author-provided rectangle lies outside the source PNG's actual native dimensions (including right/bottom coordinate 728 for 720-pixel image sides). Do **not** use those eight rectangles as exact pixel-level source gold without a separately justified coordinate transform or correction. Of the other **62** geometrically valid author rectangles, **51** contain at least 90% of pixels changed by 24 or more in their corresponding source-mutated image. The seven misses include types: layout-clip 3, layout-miss 3, layout-overlap 1. This validates an *author synthetic region consistency check*, not an independently human-labelled clipped-text or actual runtime GUI error.

The original changed pixels and mismatched reference source paths are retained outside Git under `/data/var/perceptual-independent-20261024/`. No third-party images were committed, and original files, earlier research receipts, gallery, models, real production services and all historical uncertain submissions remained untouched.
