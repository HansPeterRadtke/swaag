# Independent industrial image anomaly evaluation — new original MVTec splicing connectors

**25 October 2026. Research status: PARTIAL.** This continuation tests the unresolved owner question about visual defect analyzers for actual physical equipment, rather than only image descriptions, programmatic mesh validity or small synthetic fixtures. Source is [MVTec LOCO AD](https://www.mvtec.com/research-teaching/datasets/mvtec-loco-ad) by Bergmann et al., IJCV 2022, original real industrial product photos with external source category labels distinguishing correct arrangements, logical violations and structural damage. The original 2026 SWAAG MVTec experiment used only eighteen original-color **pushpin box** photos. This new independent product is **splicing connectors**, with one hundred thirty-four different source photos selected by hash ranking from the original training, validation and test splits, and no overlapping original source filenames or image classes. The public Hugging Face rehost is pinned to its release revision in the companion evidence JSON. All source imagery is CC BY-NC-SA 4.0 **noncommercial** and lives exclusively under `/data/var`, not in SWAAG Git.

The frozen evaluation chose **twenty-four original good photographs for normal-only reference memory**, **twenty distinct good validation photographs for threshold calibration**, and **ninety different heldout source test photographs**, balanced with thirty genuinely source-labeled good, thirty logical defects and thirty structural defects. Test labels were joined only *after* all raw image features and continuous anomaly scores and the ninety-fifth percentile of twenty normal validation scores were saved. Three fixed methods shared the same number of original normal training and validation images. One used the already installed pretrained OpenAI CLIP ViT-B/32 full-image embedding, one used its last-hidden patch-embedding one-class nearest-normal memory (not the official PatchCore implementation), and one was a simple handcrafted spatial HSV histogram nearest-normal detector as a no-pretraining control. CLIP CPU-only, no shared GPU memory allocated or production services interrupted.

## Independent true positives, false control alarms and missed industrial defects

The pooled case below uses the original **sixty** logical/structural anomaly source photos versus thirty independently sourced normal test photos. Binary cutoff was fixed using the twenty original normal validation photographs only, not tuned to anomaly positives. The AUC is from the actual continuous image score on unaltered real test photographs; ninety-five percent source-image stratified bootstrap intervals are descriptive only.

| Predeclared image screening method | Source abnormal photographs detected | False alarms / 30 true good controls | False negatives | Real test ROC AUC | 95% source image bootstrap ROC AUC |
|---|---:|---:|---:|---:|---|
| CLIP global nearest normal | 15/60 | 9/30 | 45 | 50.6% | [0.38, 0.6294] |
| HSV spatial hist nearest normal | 3/60 | 1/30 | 57 | 55.9% | [0.435, 0.6792] |
| CLIP p95 patch memory | 14/60 | 5/30 | 46 | 59.0% | [0.4666, 0.7197] |

The compact JSON report additionally preserves separate **logical versus normal** and **structural versus normal** source confusion matrices, false positives and negatives, normal-only calibration thresholds, number of source images, complete source hashes, and normal-only sample budget. If a model has high area under the ROC curve but its predeclared no-anomaly-calibrated cutoff misses defects, that is a deployment failure rather than a pass. Likewise zero false positives among only thirty clean samples is insufficient evidence of high deployment specificity. Source normal images cover a narrow photographic family; actual industrial defect types are visually heterogeneous. Do not extrapolate one original commercial inspection benchmark into real factory return rates, correct industrial CAD, missing components in all forklift renders, photo-realistic lighting or actual bearing-load physics.

## Practical judgment tied to the owner's question

A pretrained vision embedding and a domain-calibrated one-class memory can nominate suspicious patterns, but can only claim an automatic acceptance gate after seeing **independently heldout source variants, calibrated per-fault misses and control false alarms**, plus test-time cost and domain shift to the exact target assets. The very high-stakes facts in the warehouse—wrong rack orientation, missing bearing support contact, mechanical structure—must be verified from authoritative source mesh/CAD and intended load paths, not extrapolated from this photo anomaly benchmark. Where source geometry is unavailable, actual pixel detector alerts can route to human review with an explicit unknown state. No generic VLM or raw CLIP probability can prove physical soundness, photorealism, or human aesthetic quality from one picture.

**Still genuinely open:** an independent manufacturer-class source-geometry-plus-human-visible render corpus of correct and defective forklift/warehouse mechanics, exact real application GUI clipping/contrast, independently adjudicated chart-arrow direction, and natural audiovisual temporal continuity anomalies. Those are distinct from original LOCO physical-object images, which are research-use-only and not a commercial deployment dataset. No previously denied media retrieval, uncertain Calendar submission, rendering pipeline or GPU process was repeated or modified.
