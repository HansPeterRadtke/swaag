# New independent industrial photo evidence: PaDiM-style spatial source anomaly detector versus cheap controls

**25 October 2026 — owner visual perception research. Status: PARTIAL, this analysis is complete.** A new third MVTec LOCO original product category, **Screw Bag**, was used to test whether a more specifically spatial industrial anomaly analyzer substantially improves on the poor generic image VLM/CLIP detection shown by the earlier *pushpins* and *splicing connectors* source experiments. This is one external new laboratory object family, **not** an unrelated manufacturer and not an owner mechanical warehouse render. Primary source [MVTec LOCO AD](https://www.mvtec.com/research-teaching/datasets/mvtec-loco-ad) (Bergmann et al., IJCV 2022), external source photo-label classes normal, logical anomalies and structural anomalies. Original source photos and pretrained model weights are **CC BY-NC-SA noncommercial** or separate model-source licenses, and no original media is placed into SWAAG project Git. The original public HF source mirror is pinned to revision `839fee8178c10d2e50afddc671238ba85d9975d9`.

The test selection was fixed by source-independent hash BEFORE inspecting images: **24 train-normal images**, **20 separate validation-normal for the cutoff**, **30 original heldout source-good**, **30 original heldout logical-defective**, and **30 original heldout structural-defective photos**. All 134 original source media files, roughly 194 MB, were checked against upstream byte sizes and retained with SHA-256 provenance outside Git. CPU-only on busy Nitro with no GPU, full ImageNet-1K official ResNet18 weights verified by SHA-256 and original preprocessor used for a 512D global model plus a 32-channel 28x28 normal-spatial Gaussian. Its features were fixed by layer1/2/3 pretrained representations, a seeded fixed 32-of-448 channel selection, and normal-only pixel-position covariance with regularization 0.01. Two predeclared spatial image scores—**the maximum Mahalanobis difference** and **the 95th percentile spatial difference**—were compared with the pretrained ResNet18 full-image cosine-memory baseline and a simple same-budget 2-by-4 tiled HSV histogram. These are **PaDiM-inspired probes**, not an official production implementation or a preexisting certified industrial anomaly classifier.

All four methods used the same 24 original normal-reference photographs and 20 untouched normal validation photographs for a fixed **95th percentile validation score threshold**. The raw source-image scores and thresholds for all 134 images were stored before any of the thirty good, thirty logical and thirty structural source-test labels were consulted for evaluation. No threshold was adapted to visible defects, and no anomaly was used in training.

## Operational verdict

Pretrained image features and spatial normal-only models can only be assigned an automatic failure role if their **actual false alarms and misses on unseen target product photos** satisfy a separately declared operational risk budget. A spatial feature detector finding surface/texture differences still cannot prove correct screw count and arrangement, load-bearing tolerance, correct original warehouse pallet support or photo-realistic shaders and cameras. If it alerts on the final pixels, report the candidate visual problem for inspection; if it does not alert, return **not detected**, not certified correct. The original source CAD, assembly graph, actual three-dimensional triangle contacts and approved design remain the strongest physical correctness reference. This one independent product class only updates which visual model merits additional testing.

Open: a certified multi-manufacturer and owner-warehouse CAD-to-render test with genuine source part relationships, human-audited final visual defects, an independent more capable trained specialty vision model such as official PatchCore/EfficientAD, and source-matched natural bad-versus-good animation with exact human timing. Previously denied actions and uncertain Calendar submissions were not repeated. No production GPU services or customer-facing media were modified. **Research status PARTIAL.**


## Exploratory paired method uncertainty after source result disclosure

Once the original ninety heldout source labels and all four frozen method outcomes had already been examined, we performed an explicitly **POST-HOC, not untouched** stronger comparison. It resampled the **same image indices jointly across all four methods**, separately within the thirty normal, thirty logical and thirty structural source categories, in four thousand paired bootstrap draws. The exact original photo selection, checkpoint weights, image features, normal-only calibration and predicted anomaly flags remained fixed. Full paired numeric results and original private-input hash are in [`perceptual-mvtec-screwbag-posthoc-paired-uncertainty-2026-10-25.json`](perceptual-mvtec-screwbag-posthoc-paired-uncertainty-2026-10-25.json).

The spatial Gaussian p95 ranker exceeded global ResNet18 AUC by **+0.079**, but the source-image bootstrap interval **−0.087 to +0.232 crosses zero**; compared with the HSV color histogram baseline, the difference **+0.066**, interval **−0.088 to +0.218**, also crosses zero. Against the alternative spatial Gaussian **max** score, its AUC gain was **+0.192**, interval **+0.031 to +0.342**, but this comparison is still post-hoc and from one consumed source product family. The p95 method flagged eleven anomalous images missed by global ResNet, yet missed seven abnormal images global ResNet flagged, and their three false-positive normal controls were **disjoint**. Therefore even a naive OR of these methods can create new false alarms; no ensemble or AUC score can be promoted automatically into a reliable industrial reject gate. Both methods' operating-point sensitivity on this source was still around **20–27%** and poor for original logical defects. The proper recommendation remains a source/CAD-defined physical contract first, and image models only to nominate suspected visual problems for separate review.
