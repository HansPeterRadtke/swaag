## False-positive stress test of an INVALID source reference

**120/120** author-normal controls have source image bytes exactly identical to their correctly chosen same-viewport originals. This guarantees that any positive numerical pixel-difference threshold will never falsely accuse those exact controls. It is therefore scientifically invalid to interpret zero false alerts as evidence that the analyzer can tolerate dynamic application changes. For the exact same actual author-normal portrait/landscape screens, deliberately choose the **opposite approved orientation** as a reference (and resize). The pixel-only rule accuses **120/120** genuine author-normal examples (and abstains on 0). The proper source-binding rule instead abstains on **120/120** controls because the expected viewport dimensions/state do not match. This intentionally invalid-reference stress test is **not** a fair same-input performance comparison with correctly aligned screenshot reference; it establishes that reference/viewport identity is indispensable and output must be REVIEW, not semantic FAIL, for mismatched states.

Existing verified unavailable original paths were not retried; other source media were downloaded read-only, with exact SHA receipts outside Git.
