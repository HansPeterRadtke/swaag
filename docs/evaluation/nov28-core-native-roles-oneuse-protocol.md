# Fresh SWAAG core-agent native-role and error-recovery acceptance protocol

This is a **new, separate** fixed-input source task, not a replay of any earlier demonstration. It inspects the actual checked-in core-agent regression tests for native user/assistant roles and bounded completion evidence retrieval. The model must invoke real read-only filesystem tools, observe one deliberate missing-file error, recover using the directory listing and two genuine source reads, and use a genuine calculator call to add top-level Python test declarations. The independent verifier checks source revision, original source hashes, all durable event hashes/schema, one user prompt, native request roles and exact component contents, source file bytes, real tool IDs and outputs, the chronology of model-observed failure and subsequent recovery, the calculator result, and the final answer. A mock test, source listing, or an answer that merely *claims* tools ran never qualifies.

The implementation is `scripts/demos/nov28_core_agent_oneuse.py` (frozen preparation and ONE admitted run), `scripts/demos/verify_nov28_core_agent_oneuse.py` (post-run independent oracle), and `tests/test_nov28_core_agent_oneuse.py` (safe synthetic fixtures and authority-denial tests). The fixed original source names are `tests/test_action_native_roles.py` and `tests/test_completion_evidence_expansion_bounds.py`. The missing path is unique to this task. Count top-level `def test_...` declarations once even for parametrized functions. No source commit contains the user's private model address, actual transcript, user message, raw server response, API credential, private history, or private runtime state.

**One-use private run procedure:** Work from the exact verified clean canonical `main` checkout, do not use the installed stale Nitro package, use the already qualified Python 3.11 runtime with SQLite >= 3.51.3, and provide an existing private numeric model endpoint through process-local `SWAAG_CORE_DEMO_MODEL_URL`. Before running, reserve a real active Thor inference resource lease through Raspi's resource broker and register the exact shared Coder model dependency under the enrolled SWAAG core project, preserving all other consumers. The script fails closed if the lease is absent, queued, expired or belongs to another owner. Check server model identity read-only; **do not** start, stop, restart or evict the shared server.

Prepare exactly once, with a fresh evidence directory outside Git. This creates only `manifest.json`, `fixed-task.txt` and `read-only-config.toml`, with restricted permissions and hashes. The model is the currently resident Qwen Coder alias; the transport is genuinely `/chat/completions`, not the older flattened `/completion` fallback. The only model-invocable tools are `read_file`, `list_files`, and `calculator`; filesystem read root is the checked-out SWAAG repo; all model-visible shell, file writes, side-effect tools, browser, account actions, work submission and voice clients are disabled. Caching and model retries are off; independent completion verification is enabled with two rejected-attempt allowance. Max eleven selected actions and fourteen model/tool dispatches are monitored; the owned Python process is terminated on a repeated identical missing-file error or at the configured bounded wall time. **No original user task or uncertain model effect is replayed after the one-use marker is written.**
