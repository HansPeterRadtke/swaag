# Round three protocol — frozen before inference, 2026-10-24

Research goal: produce *new* measured evidence for combined versus split extraction/reasoning and correlated model errors without replaying the earlier seven scored calls or any previously uncertain request. The October twenty-fourth first continuation's `evidence/run01` and `run02` remain immutable.

Independent gold: six source cases in `formal_holdout_v2.json`. `logic_oracle.py` enumerates Boolean possible worlds, validates every observed fact and implication, and derives `yes`, `no`, or `unknown` for each question; data and oracle are committed before inference. Quotes and registry incompleteness are represented without promoting them to observed facts. The case writer reviewed the natural-language rendering, but no external human adjudication is claimed.

Prospective matrix: six cases × two *installed distinct* model endpoints (Coder Q4 and Qwen3.8 Q8). First run one greedy (`temperature=0`, seed=17) fused and one greedy split condition per model and case, case order as in the frozen JSON; then a fused mild-sampling seed-42 (`temperature=0.25`) repeat; then a semantically equivalent paraphrase fused seed-17 (`temperature=0.25`) trial. There are forty-eight distinct trials and sixty calls if all split stages succeed. These seeds are independent only within each response distribution, not independent model training evidence. Each stage uses `max_tokens=128`, identical strict schemas where feasible, `top_p=1`, no thinking, and a separate tested inference endpoint; serial calls only.

The split condition extracts a faithful task-specific facts string from the *complete original source plus question* and asks a second model call to answer using only extracted facts plus question. Fused receives the source and question in one call. This is a realistic information-loss versus latency tradeoff, not a compute-matched model-training comparison. Every stage's exact messages/schema/request, raw output, token usage, wall time, admission metadata and independent expected answer are journaled. A stage is marked dispatched before a request begins. If tool transport times out or becomes uncertain, never retry that trial. Gate refusal before any inference and cancellation between stages are recorded separately and cannot be counted as model error. Unfinished split trials remain incomplete.

The live gate requires fresh (<5-second) stable idle observations for **both** native llama.cpp servers, zero active supervisor sessions and zero queued/running/input-required workers; individual `/slots` report no processing; MemAvailable >=12 GiB and filesystem available >=10 GiB. This cannot guarantee another client never arrives in the tiny race after observation; meaningful owner activity takes precedence and stops further tests. No new models, restarts, over-context probes, service changes, GPU training, or large downloads. Only small scratch journals may be stored on Thor; source/report/test commits are on isolated Nitro research branch.

Primary descriptive outcomes: for each completed model/variant/case, oracle exact-match correctness, schema validity, full request latency, tokens, and per-case errors. For matched completed fused and split trials report paired difference without changing source data. For models/seed/prompt variants measure frequencies of agreement-correct, agreement-wrong, and disagreement, with denominator; compute correlation only when enough joint errors occur, else record not estimable. Safety-gate refusals are separately counted. There is no preregistered significance threshold or final global winner selection from six cases; these are diagnostic development fixtures, not untouched final evaluation. Future external/human-labeled unseen corpora remain necessary.

Auxiliary grammar training is separately researched from primary papers. No remotely hosted full-Qwen training was authorized by this protocol. A **genuine** auxiliary-training experiment requires separate model weights, compute-matched plain-LM and shuffled-label controls, heldout natural-language performance and resource admission; a prompt about syntax is not a training experiment. Current source-backed evidence cannot establish universal improvement.

Reproduce: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s research/agent-model-reliability-2026-10-24 -p 'test_*.py' -q` and `python3 -B research/agent-model-reliability-2026-10-24/logic_oracle.py` (the former imports and exercises the oracle). On Thor, use the frozen `run_round3.py` with an absolute *new* append-only journal path, `--max-trials` between one and twelve. The runner does not start if required model identities or supervision cannot be fetched, and does not replay any journaled trial even after an error.
