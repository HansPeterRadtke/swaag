# Round-three fixed hard-source audit protocol — October 26, 2026

This is **not** a Qwen/SWAAG production deployment or proof of agent correctness. It tests a necessary research subtask using **independently annotated real scientific claims**, not author-designed source IDs or new model votes. It is a negative/positive evidence-polarity test complementary to the original relevance task. The user specifically asks for hard negative source cases, independent labels, multiple instances and incorrect-output audits. Do not imply the SciFact source is a set of real SWAAG user tasks.

Read original `/data/infra/AGENTS.md`, the original agent relevance and agent evidence recordings, domain guidelines, prior `SOURCE_LEAKAGE_AND_MATCHED_QWEN_COST_AUDIT_2026-10-26.md` and current dirty worktree before running. Do not repeat the previously denied private data movement or Thor Qwen calls.

**Source version:** original, immutable SciFact Wadden et al. 2020 archive on Nitro at `/data/tmp/agent-model-independent-qrels-20261025/scifact_original.tar.gz`, SHA-256 `11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`. Use 5,183 original corpus papers, 809 original train claims and 300 development claims. Exclude from training the 2 source train claims whose verbatim text appears in dev (ids 871 and 1291), leaving 564 expert annotated train claim/paper pairs, from 505 claims. Evaluation: all 209 expert-annotated dev claim/paper pairs from 188 claims; the known source labels are **138 SUPPORT and 71 CONTRADICT**. Documents may recur across splits; holdout is by claim, not paper. These source counts were inspected before method specification, so this is an out-of-train outcome check, not an untouched prospective challenge.

**Outcome:** BINARY textual evidence claim polarity given a scientific claim and a specific original paper's evidence. Positives mean source expert says SUPPORT. Negatives mean source expert says CONTRADICT, **NOT** 'irrelevant' or 'absence of evidence'. Confusion matrix: positive TP = predicts SUPPORT when source SUPPORT; TN = predicts CONTRADICT when source CONTRADICT; FP = predicts SUPPORT when source CONTRADICT; FN = predicts CONTRADICT when source SUPPORT. No neutral/NEI labels or true-negative relevance documents are available here. Scorer must not treat missing source annotations as negatives. Every expert alternative rationale is an OR of full conjunctive sentence-index sets. The minimal independently expert-marked rationale (shortest, then lexicographic) is an **oracle evidence-source upper bound**, not obtainable automatically.

**Source inputs, identical independent eval cases:** four variant evidence contexts for each same original claim/paper pair: `oracle_min_rationale` (shortest original expert rationale only), `bm25_top3` and `bm25_top5` (from immutable *previously frozen* archived dev BM25 selected sentence IDs), and `whole_abstract` (all original sentences). Do not tune the BM25 method. Verify `evidence/scifact-offline/source_evidence_case_predictions_v1.json.gz` SHA-256 `0e0f797b9cafdd0abb7a15ff06b898b9ad8ef4d15bdf4f22ec609831872a076e`; match all 209 original claim/document expert labels and exact rationale alternatives to that archived file, abort on drift. Source-version edge case found on the first validation attempt **before any outcome scoring**: eight real abstracts have three or four sentences, so the archived BM25 top-five list has `min(5, original_sentence_count)` items. Do not exclude these cases or pad them with invented sentences. Measure complete-rationale retention, median and mean source characters/words, and original paper and citation IDs. Gold oracle is used only to construct a declared reference input, never silently promoted to an automated retriever.

**Equal case/budget comparisons (no LLM inference):** constant SUPPORT prior; claim-only TF-IDF + balanced logistic, evidence-only TF-IDF + balanced logistic, joint `CLAIM` + `EVIDENCE` TF-IDF + balanced logistic, and joint pair character TF-IDF (char_wb 3..5) + balanced logistic. Both word models use lowercase word 1..2 grams, sublinear term frequency, L2 normalization, `min_df=2`, at most 50,000 features. Character model uses `min_df=2`, max 30,000 features. Logistic solver `liblinear`, `C=1.0`, `class_weight=balanced`, `random_state=20261026`, `max_iter=1000`. Train on 564 original train claim/paper gold **minimum rationale** pairs, with original label once per pair, never dev examples or labels. No tuning thresholds: score probability `>=0.5` as SUPPORT; otherwise CONTRADICT. Claim-only and constant are negative controls to assess reliance on source evidence. Each trained classifier is **fixed across all four dev source variants**; any variant drop is input-evidence and distribution shift, not an isolated candidate architecture win. Holdout dev data are evaluated exactly once for this version, retaining all unsuccessful methods. Source-preparation and model inference cost, number of CPU classifier fits and predictions and RAM high-water mark are measured; no GPU memory, Qwen tokens, real queue, reviewer costs, or end-to-end tool effects are available. Runtime source length in words is only a proxy, **not actual Qwen/BPE tokens**.

**Hard groups:** source expert CONTRADICT versus SUPPORT; all expert rationale alternatives require 2+ sentences (no one-sentence proof); two or more possible expert alternatives; same claim has multiple distinct expert paper instances. Report errors by each, pair-level confusion, original-claim clustered bootstrap confidence interval for joint word vs majority prior and evidence-only on `oracle_min_rationale` (1,000 fixed seed resamples). Report a case-level *error ledger* including claim/paper IDs, authoritative label and rationale sentence IDs, retrieval completeness, predictions and raw confidence values for every dev pair (no copyrighted/private original text in Git). Model class confidence **does not establish correctness or calibration**. Identify cross-paper prediction contradictions among repeated instances of the exact same claim that have the same original expert polarity; report, do not adjust ground truth.

**Essential limits:** Training on expert gold rationales means this is a supervised *CPU polarity classifier* sanity check, not a Qwen reviewer, not a measured user-versus-worker relevance score, not a full specialist model workflow, and not a deployable SciFact fact checker. Source documents recur across train/dev. Recall/F1 at corpus-wide document discovery is different: these dev cases are **known-evidence document pairs** and assume correct document identity. Existing Qwen 4/5 vs 5/5, numeric-vs-word 3/5 vs 3/5, selector-only cost lower bounds, and matched Qwen grammar auxiliary-training gap remain as in the previous verified work. No production changes or new scheduled tasks.
