The owner asks which task-specific evidence belongs in user replies versus worker and orchestrator calls; whether constrained ordinal words outperform numeric relevance ratings; when serial specialist/reviewer LLM calls actually improve *independently verified final correctness per total GPU/token/latency cost*; and whether *training-time* grammatical auxiliaries improve current transformer models. The one decisive absent resource is a **matched corpus of completed original SWAAG tasks with independently verified final effects and source receipts, plus full two-stage Qwen inference/GPU timings**. Developer-selected source snippets and researcher relevance scores do not supply independent task-outcome gold. Qwen model votes are not an independent grader.

Previously completed conditional evidence is documented in `DIRECT_ORIGINAL_QUESTION_VERDICTS_2026-10-25.md`. Five matched Qwen full-context source answers were Coder 4/5, 1.270-second mean, and Qwen3.8 5/5, 4.544-second mean; this does not isolate model size or generalize from five tasks. Five matched numeric/text judgments each matched the researcher's anchors on 3/5, with numeric absolute-error sum 10 versus text 16, and no blinded human labels. A single selector call already exceeded a completed direct response on one Qwen task, while a second answer was uncompleted. Matched-FLOP Qwen grammar training is unperformed; published controlled syntax studies have mixed task-dependent results. A no-output gate saw only 14/77 and 19/102 externally graded failures in the pre-existing independent matched-compute study. None of these is complete local end-to-end strategy gold.

## This round: frozen equal-*LLM*-budget control, source-of-gold status, and new observed failure

Instead of repeating explicitly denied Thor inference transfers or disturbing production GPU workers, the experiment uses the **actual committed SWAAG foreground claim verifier** at `src/swaag/foreground_reply_evidence.py`. It compares (A) unchanged pass-through, (B) unconditional reject/escalate and (C) the SWAAG verifier on **identical proposed replies and evidence**. Each arm needs zero LLM calls and zero new GPU inference. The verifier has a small nonzero CPU cost; therefore this is *matched model inference budget*, not identical total compute cost. It tests a deterministic verification subsystem, **not direct Qwen versus multi-call Qwen final accuracy**.

The frozen 32-case inputs, gold basis, source hashes, exact guard verdicts and microsecond observations are in `verified_foreground_guard_v1.py` and `evidence/foreground-verified-guard/frozen_same_budget_v1.json`. Only newly created files are tracked; prior concurrently uncommitted selective-escalation analysis remains untouched.

**Gold/provenance boundaries:** Twenty-four `anchored` candidate inputs and allow/reject contracts are derived from pre-existing SWAAG acceptance tests `test_fast_worker_claim_evidence.py` and `test_fast_reply_evidence_guard.py` (file hashes frozen). They are explicitly **not a blind holdout**, not model-generated samples and not representative distribution estimates. The only ground-truth predicate scored is whether the proposed statement can be delivered *unchanged*; sanitizing text is a correction, not an unchanged acceptance.

The separate source-anchored SWAAG pytest tests could **not** be collected in the existing Python 3.12 `/data/venv` (missing `opentelemetry.context` and related packages). These are test-environment blockers, not failures of a running production instance. Targeted standalone `unittest` is the available reproducible test for this round.

There is **no measured Qwen stage-2 completion, GPU lease/admission, queue time or reviewer confusion matrix for the present inputs**.

## Operational conclusion and next acceptance gate

Keep one capable first foreground model call and exact authoritative current state. A fast source verifier is valuable but cannot be used as the sole semantic or effect-validity oracle: its success on existing tests misses natural paraphrases and unsupported action-completion claims. For worker effects, prioritize independent executable assertions and receipts; ambiguous foreground completion/status claims should receive fresh state evidence or be delegated, not upgraded from a plausible string or another model's vote. These 32 controls are a **developmental adversarial suite**; do not report a general guard accuracy or production regression rate from their biased mix. The six misses are practical candidates for distinct future blinded prompts, human/source-verified Qwen outputs and an improved guarded policy, but no production behavior was changed here.

To settle the owner's main model-architecture decision, obtain a pre-registered independent test set of **real original SWAAG jobs and effect receipts**, without permission-denied source movement; complete direct and both specialist stages plus reviewer on the **same cases** under the same model/quantization, source/token budgets, verified GPU admission, and independent accept/reject labels. Score entire final task accuracy and reviewer confusion (wrong-to-right as well as right-to-wrong) and count all model calls, source retention, tokens, queue and GPU-memory peaks. Numeric/text source selection and modern syntax-training claims still need their separate honest matched experiments.
