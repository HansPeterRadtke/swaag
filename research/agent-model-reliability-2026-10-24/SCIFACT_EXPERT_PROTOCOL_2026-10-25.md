The October seventeenth recording also asks whether the harness improves task accuracy by preserving the correct source facts, and whether specialist calls outperform combined ones. The earlier tiny Boolean fixtures, failed extractors, and unadjudicated SWAAG importance annotations do **not** answer that; retain those original negative findings without relabeling. ## Authentic primary source and independent annotations

The original Allen Institute SciFact release is https://github.com/allenai/scifact, as described in Wadden et al., *Fact or Fiction: Verifying Scientific Claims* (EMNLP 2020, https://aclanthology.org/2020.emnlp-main.609/). Unlike the earlier ARES **synthetic example output** file or NFCorpus's citation-link-derived grades, SciFact contains *expert-written scientific claims, annotated SUPPORT and CONTRADICT abstract evidence and rationale sentence indices*. The immutable source archive `https://scifact.s3-us-west-2.amazonaws.com/release/latest/data.tar.gz` has SHA-256 `11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`. This source was downloaded to Nitro private scratch; Thor must never download or extract the full dataset. The archive's `data/claims_dev.jsonl` comprises three hundred expert-written claims and 338 evidence rationale annotations (216 SUPPORT and 122 CONTRADICT, including repeat rationales for the same claim/paper). `data/corpus.jsonl` contains 5,183 scientific paper abstracts; the expert annotations include exact original sentence indices. `data/claims_test.jsonl` omits evidence labels and is **not** silently treated as ground truth. This dataset is explicitly marked noncommercial in the released materials; no original claim or abstract text is copied into public Git.

`prepare_expert_scifact_v1.py` verifies the source-archive hash before reading. It merges multiple rationales for the same source claim/doc pair, rejects conflicting source labels, and excludes invalid indices. It selects exactly **forty-eight unique claim/document pairs**, twenty-four SUPPORT and twenty-four CONTRADICT, by a fixed source-label-by-abstract-length stratified scheme with seed `20261025` and fixed 500–3,600 character source length bounds. The complete immutable **public manifest** `scifact_expert_manifest_v1.json` retains labels, claim/document source IDs, rationale indices and source SHA-256 identities *but no abstracts or claim text*. Original source and fully reconstructed private selected examples remain outside public version control under `/data/tmp/agent-model-independent-qrels-20261025` on Nitro. The preparation script can regenerate every case from the original exact hash. The dataset selection was frozen **before any SciFact Qwen inference**; no model output influenced which cases/labels were kept. The balanced sample is explicitly **not** representative of the prevalence of scientific support/refutation in real agent work.

## Frozen controlled model-call conditions

Existing Thor resident Qwen3-Coder Q4 and Qwen3.8 Q8 endpoints only. The same unaltered scientific claim and exact original abstract/title are evaluated in four preregistered conditions per model: `direct` answers SUPPORT / CONTRADICT / NOT_ENOUGH_INFO using the full paper abstract; `expert_rationale` answers using only exact expert-annotated evidence sentences (source-selection upper-bound diagnostic, not a deployable oracle); `select_then_answer` asks the same model to select up to four existing original sentence IDs from the full source and then makes a **second** model call with the identical claim and those exact verbatim sentences; `alternate_direct` uses a semantically equivalent but different instruction with mild sampling (temperature 0.25, seed 42) on the full source. The other three conditions use temperature zero, seed 17. Each call uses a constrained JSON schema, no thinking mode, maximum sixty-five output tokens and original source premises. The split stage must not generate an uncontrolled new summary. Output labels are not presented to the model. The optional NOT_ENOUGH_INFO can count as incorrect against an independently annotated supported/contradicted pair; it also provides an explicit abstention signal.

The fixed matrix totals forty-eight cases by two resident models by four conditions = **384 trials** if all can run. Each command is bounded to twelve newly attempted trials. Every submitted inference stage has a fresh SWAAG supervisor/worker-status check, independent native `/slots` checks for **both** model servers, and existing host-memory and disk reserves; any uncertainty immediately stops that batch. The trial ID is durably recorded before any model request and **never replayed**, including after timeout, missing reply, selector failure or work contention. An attempted second call that fails admission remains incomplete, not a semantic failure. No model loading, fine-tuning, model/server restart, production worker interference or parallel inference is permitted. The scheduler cannot guarantee exclusivity after the instantaneous idle check; capture that limit in results.

Primary independently adjudicated outcomes: exact agreement with expert label for completed judgments; SUPPORT/CONTRADICT confusion and abstention rates by model and condition; matched same-case direct versus source-selection correctness; selected-sentence coverage of annotated rationales (not equal to final answer correctness); total input plus output token and full wall latency across **both** specialist stages; paired cross-model wrong/wrong, wrong/right, right/wrong and right/right contingency cells for matched source/prompt conditions; and within-model prompt/seed changes. Error correlation is only statistically estimable when enough matched wrong and disagreeing cases have completed; agreement itself never becomes new truth. Small and censored observed samples must not be pooled with unmatched trials to claim an ensemble winner. A specific problem could have multiple source annotations of different rationale scope; both label and original source always remain in the independent manifest.

Confounders: SciFact dev claims may have appeared in pretrained model data; the two installed Qwen variants differ in architecture/training and quantization; expert rationales are not always sufficient in isolation without the full abstract or study context; full prompt/prefill overhead, alternative prompt wording, turn order and Thor GPU contention affect latency. These are real independent scientific-evidence judgments, **not** a measurement of SWAAG's source-traceable tool execution. An additional fresh holdout of authentic real agent messages with independently verified final effects remains necessary for the owner's broad thesis. Direct or specialist performance on this particular corpus cannot prove syntactic auxiliary training gains; those require separately compute-matched training.
