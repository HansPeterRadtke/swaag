## Final decision labels, zero-call and source-cost contracts

Each policy receives the exact original claim text, its *known source paper* and the same original frozen BM25 top-three sentences or complete original abstract. It may output exactly one **full user-visible disposition**: `supports`, `contradicts` or `needs_independent_verification`. This is a completed output of the lightweight reference decision pipeline, **not an actual SWAAG model-to-tool trajectory or true verified user research answer**. The latter disposition is safe non-assertion but is **unresolved** rather than correct. When a model confidently asserts SUPPORT despite expert CONTRADICT, count `false_support`; the opposite is `false_contradiction`. When a returned label happens to match expert gold but the supplied BM25 top-three lacks *all complete rationale alternatives*, mark it `coincidentally_correct_but_missing_complete_source_evidence` rather than verified source-backed final success. Oracle expert rationale is used **only after final outputs** for scoring that distinction, never as a real-time reviewer trigger.

**Frozen policy arms** (no threshold tuning or winner selection after looking at dev outcomes):

1. `zero_call_support`: always asserts SUPPORT; reveals base-rate distortion with zero semantic call and 100% false-support risk on contradictions.
2. `zero_call_abstain`: always refuses to assert, total coverage zero, zero false facts, no model inference cost; not a successful research answer.
3. `one_word_top3`: original trained word unigram/bigram pair classifier, one call, frozen BM25 top 3.
4. `one_word_full`: same word model, one call, full source abstract; direct longer-context comparison.
5. `one_char_top3`: character TF-IDF pair classifier, one call, BM25 top 3.
6. `two_consensus_top3`: **always** call word then char on the same three sentences; accept their answer only on agreement, otherwise abstain. This tests correlated wrong/wrong effects and latency of an unconditional extra reviewer.
7. `selective_review_uncertain`: word first on BM25 top 3. If score within inclusive `[0.4,0.6]`, call the char reviewer on the **full original abstract**; accept only if both agree, otherwise abstain. Else retain word label. This tests optional additional source and selective compute with a *fixed* threshold (not a calibrated probability guarantee).
8. `selective_review_support`: word first on BM25 top 3. If it proposes SUPPORT, always ask the char reviewer on the complete source; if they disagree, abstain; otherwise retain. If word proposes CONTRADICT, return directly. This targets high-cost false SUPPORT on human-marked contradictions without privileged labels.
9. `one_word_abstain_uncertain`: only word top3; emit abstain for scores in `[0.4,0.6]`, no reviewer calls.
10. `two_consensus_full`: always call word then char on *full* original abstract and accept only unanimous opinions; otherwise abstain. Paired source-budget upper-bound comparator, not a model ensemble quality claim.

All first and optional second decisions are **real local scikit-learn calls** on Nitro CPU, in test-isolated mode, with the same already-configured training split and identical original case IDs. Keep complete per-case raw model probabilities, model call counts, actual per-call CPU wall clock, total input source words/chars across repeated stages and final emitted string. No private copyrighted source text may be written to Git. Time training separately from serving; end-to-end source loading/hashing and total wall separately. Count repeated source tokens if passed to a reviewer. Source words are whitespace proxies, **not actual llama.cpp tokens**. Run CPU at normal/low priority and limit BLAS/OpenMP threads to one to avoid production disturbance.
