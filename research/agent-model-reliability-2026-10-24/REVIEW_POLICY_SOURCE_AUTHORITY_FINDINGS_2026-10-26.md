# SWAAG agent relevance, source authority and independent review-policy outcomes

**October 26, 2026 — round five. Research remains PARTIAL overall.** This round tested actual *final source-scoped conclusions*, abstentions, error corrections, reviewer-induced new errors, CPU latency and two-model costs against **original independent human expert annotations**. It also verified a deliberately selected subset through SWAAG's real user-facing communication code with isolated simulated model responses. Nothing was deployed to production; the uncommitted prior selective-escalation research branch files remain untouched. The entire method and thresholds were frozen in `SOURCE_AUTHORITY_REVIEW_POLICY_PROTOCOL_2026-10-26.md` before running the new policies. No current Qwen inference, GPU allocation, previously denied data transfer or Calendar operation was performed.

## Original owner questions and operational conclusions

The **input-construction criterion** is source-complete relevance to the actual *consumer*: an ordinary spoken status answer needs current authoritative progress and material blocker, a worker needs actual original requirements and results, and orchestration needs dependencies, timestamps, controls and receipts. These are distinct relevance dimensions, not one numerical popularity/importance scale. A global score cannot independently establish source truth or override the latest explicit user correction. On installed Qwen, **five** prior paired numeric vs textual enum judgments each matched research-author anchors **3/5**; there is no independent human-labelled rating winner. Use source-purpose-scoped ordinal metadata only as a navigation hint, not as probability of truth.

The prior **six matched actual Qwen** research contrasts had **5,593 evaluated tokens / 20.874 seconds for complete direct answers** versus **5,600 tokens / 21.827 seconds for selection *stage one alone***. No genuine model-selected second answer completed; the old research's fixed `r1/r2` relevant-source identifiers leaked the label. This supports the interim one-capable-first-user-response policy, not a universal no-decomposition law. Model reviewing must be validated by independent effects/source references: one archived Qwen Coder `old_message_authority` case explicitly answered `old_quote_overrides_current` incorrectly (1,016 total tokens, 1.549 seconds), while Qwen3.8 answered `current_request_and_supersession_win` correctly on the same source question (1,031 tokens, 4.951 seconds). The unchanged authoritative `docs/fast-long-history-candidates-2026-10-21.md` explicitly says old quoted user instructions may be superseded and the current finalized user message governs. **One cross-model correction is not a statistically valid reviewer policy or size/quantization effect.** Published grammatical/structural auxiliary training can improve some source datasets and regress on other metrics, but no current-Qwen training-time same-FLOP comparison has been performed. Prompted grammar tags do not substitute for training-time auxiliary loss.

## Independent original source gold; scoped truth rather than source voting

The primary source is Wadden et al. original SciFact 2020 release, locally verified SHA-256 `11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`. Previously frozen original BM25 sentence rankings SHA-256 `0e0f797b9cafdd0abb7a15ff06b898b9ad8ef4d15bdf4f22ec609831872a076e`. Two word-for-word overlapping train claims (IDs 871,1291) were removed. **564 human-labelled original training claim/paper pairs** from 505 claims trained two existing small CPU TF-IDF/logistic classifiers against original expert oracle rationale passages. The final decisions were evaluated on **209 original expert-labelled development claim/paper pairs from 188 distinct claims**, with **138 SUPPORT and 71 CONTRADICT**. The development split was already used for prior retrieval research and 124/209 evaluated paper identifiers also occur in training, so these are *independent expert annotations and held-out claim texts for the classifier*, not a new previously unseen development set for the broader research program. No independent SciFact test-gold is available and no scientific text was copied into Git.

Scientific polarity is **relative to one statement and one document**. Across the original scored source documents, **179 paper IDs** have expert SUPPORT *and* CONTRADICT relations to different original claims. For example, source paper `16472469` supports original train claim 992 and contradicts original train claim 990, with several additional contrasting expert relationships. Original dev paper `4709641` supports claim 56 and contradicts claim 57. Thus a global credibility label on the document, agreement across document mentions, or an old quoted sentence is insufficient to infer support of the *present* question. An original CONTRADICT is a **genuine negative to an affirmative support answer**, but it is still relevant evidence; unknown/unannotated documents cannot be relabelled as irrelevant negative gold.

## Exact deployment-policy comparisons on the *same* source cases

The same previously configured CPU lexical classifiers and original sources were used in **ten frozen policy arms**. `word top3` receives the previously frozen BM25 top-three original paper sentences; `full` reads the entire identified paper abstract; `char` is a separately fitted character-ngram CPU classifier. `consensus` accepts only if both model outputs agree, otherwise *abstains*. `uncertain` reviews only if the first raw support score is within `[0.4,0.6]` (not calibrated), with full original abstract supplied to reviewer. `support` always reviews a proposed SUPPORT decision with the full abstract, accepting agreement or abstaining. There is **no expert oracle at inference time**. Every policy emits one final user-visible disposition, `The cited paper supports ...`, `... contradicts ...`, or an explicit “cannot verify reliably” abstention. **An abstention is not graded as a correct final research answer.**

Measured values are **complete real local CPU classifier calls** per policy across all cases, with all first/reviewer model stages counted. The data pipeline validated and loaded source archives, trained both models, evaluated ten arms and saved all per-case details in about **17.9 seconds overall**, with source loading 0.78 seconds, one-time fitting word 0.29 seconds and char 1.40 seconds, and maximum process resident memory 332,500 KiB (Linux ru_maxrss). Classifier call CPU wall under shared Nitro load is not isolated performance, GPU model latency or future Qwen inference cost. Source words are whitespace words, **not model tokens**. Paper discovery/retrieval is treated as an existing frozen prerequisite and its online expense is excluded from the per-classifier serving costs; these are not full real-agent start-to-finish financial costs.

The direct word top3 classifier made **53 false SUPPORT claims against the 71 original expert contradictions** and **59 false CONTRADICT claims against the 138 genuine supports**, 112 wrong in all 209 expert-labelled cases. Unconditional two-model consensus reduced asserted mistakes from 112 to 103 **only by abstaining on all 19 disagreements**, and withheld **ten previously correct** answers along with nine incorrect ones. It doubled classifier calls and reduced correct asserted answers from 97 to 87. Selective uncertain review required **115 additional model calls**, reduced false assertions to 96 but also reduced correct assertions to 91 and abstained on 22 pairs. Targeting all proposed SUPPORT answers required **132 extra model calls**, left 103 wrong final assertions and 11 abstentions. The source sets are too small and distribution-shifted to establish a production optimum, but these particular CPU strategies do not justify autonomous model-vote verification.

**Cross-model reviewer dependence on identical original inputs:** Of 209 paired expert cases, **87 both correct, 103 both wrong, 10 word correct/char wrong and 9 word wrong/char correct**. An unconditional char override would make **ten new** errors while fixing only **nine old** errors. Even a retrospective oracle allowed to select the correct of these two classifiers wherever one is right could recover **at most nine** errors beyond the first classifier, with **103 shared-error cases irrecoverable by choosing either candidate answer**. This *oracle upper bound* is not an online verifier and cannot be used to select answers from live model results. A 1,000-resample cluster bootstrap by **188 original claims**, keeping multiple papers together, gave descriptive two-consensus minus single-word top3 differences for incorrect decisive assertions **−4.31 percentage points [−7.28, −1.51]**, correct decisive assertions **−4.78 points [−8.10, −2.22]** and abstention **+9.09 points [+5.48, +13.08]**. Such intervals do not prove reviewer *factual improvement*: both wrong and right answers were suppressed.

**Source sufficiency error:** BM25 top-three retrieved a *complete* independently marked expert rationale for only **168/209** cases. The direct word top-three classifier happened to match the expert polarity on 97 cases, but on **20 of those 97** the presented source *did not contain any complete original rationale*. Therefore those 20 final correct labels cannot be called source-grounded successful explanations. Adding the complete abstract made the full expert rationale available on all 209 but the word classifier still got only 100 right, 109 wrong. A longer evidential context is not a substitute for semantic reasoning; a correct-looking JSON/disposition is not an independently verified result.

## Cross into the genuine SWAAG user-facing persistence path

Six **deliberately diagnostic, posthoc-selected** original independent-human-labelled source cases were supplied as real original claim text plus verbatim original BM25 paper excerpt to **the unmodified `CommunicationService.iter_orchestrator_message` and real event/history persistence**, using the previously observed CPU classifier verdicts as **scripted FakeModelClient outputs**. These include both opposite expert claim/document relationships for paper `4709641` and four original high-value wrong-decision cases. All **12 final user-facing trajectories** (6 original cases × 2 source policies) completed, persisted exact `turn_finished` and `control_message_processed` hashed receipts, preserved exact input source text in the private temporary model prompt and passed idempotent control-ID replay without duplicate inference or tools. For **both** single-word and two-consensus policies, **5/6 original source-gold terminal replies were wrong**, even though **5/6** initial contexts had an entire expert rationale available. This intentionally selected 5/6 is *diagnostic only, never a population error rate*; both policies happened to output the same polarity on each selected case. Both arms each had six *fake* foreground calls, **zero actual Qwen**. The service-only latency excluding all CPU model training/inference for these six was approximately **8.04 seconds** (single word decisions) and **7.05 seconds** (precomputed consensus), affected by runtime scheduling and not a basis for performance ranking. Source text, scientific claims and raw evidence passages remained in temporary private working memory; only IDs, source hashes, final verdicts and receipt hashes were committed.

This establishes a specific deployment issue: a valid source prompt and two agreeing CPU model predictions still lead to a persisted incorrect **final user-visible** claim if SWAAG's foreground acceptance has no independent scientific semantic verifier. It **does not** establish Qwen runtime error rates, GPU cost or the viability of an integrated real-time reviewer. In the separate previous 23-case SWAAG scripted worker/status study, the temporary guard reduced unsupported completed answers from 12/23 to 1/23 but increased simulated model calls from 24 to 37. That guard was never deployed and the 23 synthetic status labels are not independent human scientific gold.

## Operational policy decision and remaining evidence limits

**Do not deploy either of these CPU source-polarity classifiers as an autonomous factual verifier or a Qwen reviewer.** On actual original expert-labelled contradictory papers they falsely claim SUPPORT far too frequently. **Do not replace independent evidence checks with model consensus**; both-agree can be jointly wrong. For current SWAAG, retain one capable first communication inference with the exact governing user request and current fresh worker/world snapshot. For consequential worker effects, run independent actual tools/tests/receipt checks and re-ask only when there is an actionable **source-grounded or externally verified** failure or missing premise. If the complete evidence or reliable verification is absent, keep uncertainty explicit rather than letting a second model's agreement certify success. Specialist calls for lengthy independent background jobs can still be valuable, but need their own completed matched positive and negative actual-task comparison including all calls.

**Main unresolved hypothesis remains** actual Qwen3-Coder versus Qwen3.8 role-conditioned relevance, ordinal-vs-numeric human-rated labels, complete same-task direct-versus-decomposed+reviewer final correctness and total GPU/queue/VRAM/token costs, and matched-FLOP modern transformer syntax auxiliary training. The permitted investigation deliberately did **not** repeat earlier denied original source transfers or model operations. A fully qualified SWAAG deployment recommendation requires a truthful original worker/action source-gold corpus, unbiased capacity-admitted live service inference trials and independently checked effects; neither CPU lexical study nor scripted service proof supplies that.
