# SWAAG archived Qwen evidence-selection audit — October 26, round 2

## Direct operational answer

The existing local data **cannot establish** that per-task source-selection model calls or serial reviewer/specialist calls improve completed SWAAG task outcomes. The fastest grounded original-first-answer route remains **one capable Qwen call with authoritative current state and exact source context**, and deeper verified worker work separately. Numeric vs textual ordinal ratings are still inconclusive at five matched researcher-rated trials each; an independent worker/user answer gold is absent. Training-time grammar auxiliary gains are task-dependent in published studies and unmeasured on equivalent current Qwen weights/data/training compute.

**New finding that materially changes prior interpretation:** the existing research's eight `context_grounding_v1.json` tasks *all* designate relevant evidence IDs exactly `r1` and `r2` while the three decoys have IDs `d1` to `d3`. The dataset generator explicitly assigns this role-coded scheme. Thus selection of `r1`+`r2` may be achieved with **zero semantic reading and zero model inference**. High apparent support recall on this task set does *not* validate learned model relevance. Input question and authentic exact source paragraphs are not fake; the researcher-authored source-identification labels are simply contaminated as a blinded relevance test.

## Real original evidence and reproducibility

The full prior frozen eight-case set and six archived research journal files were inspected read-only; the entire original log population was retained, not just completed successes. The new `audit_qwen_source_leakage_20261026.py` independently verifies SHA-256 of the archived dataset, its original generator and **all six journal files**, and all **40/40 exact original SWAAG engineering-report passages**, including complete file hashes and character offsets. Their source files cover original worker progress, current worker-world snapshots, history lookup, and tokenizer/context correctness. It verifies original `begin` case/gold consistency and distinct model routes before scoring any returned data. Reproduced raw evidence is stored in `evidence/source-leakage/archived_qwen_source_and_cost_v1.json`; previous journals and experimental results remain unmodified. There were **150 event records**, but **56 byte-identical repeats** across copied journal files, leaving **94 unique events** on **31 distinct planned trial IDs**. Zero conflicting duplicate events were found. Counting copied journals as extra model observations would be wrong.

**Completeness/missingness:** the original plan is 8 authentic source questions × 2 actual resident Qwen endpoints × 3 strategies = **48 planned** cases. From the preserved Nitro archive: **9** complete direct full-evidence answer trajectories (**8** match the researcher's answer, **1** does not); **4** complete privileged *researcher-gold-selected* answer trajectories (**4/4** match the researcher, but this is an oracle-selected input); **8** model-selector first stages with no answer-stage completion; **10** attempts refused by the idle-admission gate before inference; **17** planned cells not attempted in the preserved evidence. **Zero genuinely completed two-stage model-select → final-answer chains.** Those eight selector cases are capacity/interruption *censored*, not eight semantic wrong answers, and unattempted cases are not failures. The nine observed full-answer completions comprise Coder **4/5** correct and Qwen3.8 **4/4** correct against developer-authored answer choices. Only four cases overlap as fully completed Coder/Qwen3.8 full-answer pairs in this available Nitro archive; earlier references to five matched cases and a Qwen3.8 5/5 must not be silently ascribed to these particular Nitro files. An additional original source might exist elsewhere, but was not accessed or claimed in this audit.

For the sixteen planned *direct* full-answer cells, only nine were observed. The eight successes among the nine establish **a worst/best descriptive completion-bound of 8/16 to 15/16** if every missing answer is respectively wrong or right. These are *not* confidence intervals; the censoring is related to GPU admission and trial order rather than guaranteed missing at random. The 8/9 completed-only rate is not an unbiased forecast of new agent tasks.

## Exactly matched source-selection comparisons and actual inference cost

Among eight previously executed actual Qwen selection stages, the model selected **18 original source IDs**. Under the original (nonindependent, label-leaking) two-source research gold, its source-confusion matrix is **TP 16, FP 2, FN 0, TN 22** across eight five-passage questions: supported-evidence recall **100%**, selection precision **88.9%**, and false-positive fraction **8.3%** among 24 declared decoys. These values must **not** be labeled independent semantic accuracy. The zero-call role-ID shortcut always returns `r1,r2`, achieving **TP 16, FP 0, FN 0, TN 24**, perfect researcher-label agreement without reading a word of content. As a less contaminated CPU comparator, fixed-form retrospective source-ID-blind BM25 over the exact original question and passage text, with the **same number of selected passages per Qwen trial** (two or three), yields **TP 14, FP 4, FN 2, TN 20**, or **87.5% researcher-label recall, 77.8% selection precision, 16.7% declared-decoy false-positive fraction**. The comparison distinguishes evidence-budget matching from **model-compute-budget** matching: zero-inference BM25 does not reproduce the Qwen inference cost. The role-label shortcut dominates only because of how researcher support IDs were named. It is invalid to conclude from these observational metrics that Qwen is a better *real-world* source selector than blind BM25, or that BM25 is truly worse than Qwen on independent goal evidence.

All eight original selector first-stage model calls together already consumed **7,669 original recorded evaluated tokens and 28.367 seconds wall time**; the second stage never produced a final answer. In **six truly matched identical original case+model** pairs where both a direct final answer and a selector first stage exist, direct completion consumed **5,593 tokens and 20.874 seconds**, while selector stage one alone consumed **5,600 tokens and 21.827 seconds**. Its first stage was already slower in **five of six** matched pairs, even before adding the mandatory answer inference. Differences are descriptive, and backend GPU contention was not recorded sufficiently to isolate pure inference latency. Complete direct accuracy for those six is **5/6** against the author-defined answers; selector-first *final* accuracy is **unknown, not zero**. No unpermitted batch was retried; no model process, GPU routing, service or production source was touched.

## New same-source identifier-neutral follow-on artifact

To remove this particularly serious experimental artifact without moving or modifying private raw records, `prepare_opaque_context_v2_20261026.py` creates **two versioned files** from the same original eight questions and forty unchanged SWAAG source paragraphs. `source_opaque_model_input_v2.json` retains identical passage text/order/document hashes/character offsets and unchanged question/options, but replaces all `r1/r2/d1...` strings with source-content-derived, uniform opaque `s_<hash>` identifiers. No gold answer, support label, relevant/decoy role hint or evaluation annotation is included in the model-facing file. The separate `source_opaque_researcher_labels_v2.json` maintains original researcher-chosen supports and answer keys for subsequent scoring, and explicitly says this is **not independent human gold**. A zero-call lexical baseline returns the same underlying source spans under original versus opaque IDs, as an ID-neutral method should. **No new Qwen inference was performed against the opaque candidate dataset, so there is no new ID-neutral Qwen quality estimate.** This is a controlled correction of an existing label leakage flaw, not a new blinded externally sourced task set.

The measured error targets for this round are **original researcher-labelled source selection** and **original researcher-authored source-answer choices**, not independently adjudicated complete worker action outcomes. No exact independent human relevance labels, real source-grounded full SWAAG worker effect receipts, completed specialist second-stage model answers, reviewer right-to-wrong or wrong-to-right corrections, GPU queue/VRAM traces, or comparable current Qwen training runs are present. Therefore the original scientific question remains **PARTIAL**.
