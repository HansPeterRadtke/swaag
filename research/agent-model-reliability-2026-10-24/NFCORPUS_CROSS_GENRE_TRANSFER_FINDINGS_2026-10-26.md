## Answers to the original owner questions: direct, conditional and evidence bounded

1. **User-facing versus worker relevance**: the evidence and owner's original October 17 recording require separate task-purpose relevance dimensions, exact original instruction and source authority/freshness. An assistant response needs the actual user-requested status, verified result and material blocker. A worker needs exact original tool input/results, no-loss source premises and prohibitions, and executable outcome checks. Orchestration needs worker/task/dependency revisions and effect receipts. One permanent relevance number is not enough. The original 64 labels on 29 actual SWAAG report excerpts demonstrate **context sensitivity by researcher assignment**, but **not independent human-rated model reliability**. The production-path earlier 23-case *scripted model* test measured 12 unsupported completed user claims with SWAAG's committed foreground guard versus 1 under an undeployed stronger guard, at 24 versus 37 fake-model client requests; that is a harness result, not a measured real-Qwen rate.

2. **Numeric versus ordered textual relevance scales**: the actual five source/role/model/seed matched Qwen pairs each matched 3 of 5 researcher labels for numeric 0–8 and mapped nine-level ordinal words. Numeric absolute ordinal error was 10 versus 16, but five tests and single-researcher extreme-label gold are not enough to choose a winner. The present **external graded retrieval judgments** concern original source links, not actual *model ratings*; they cannot settle numeric-token versus textual-enum effects or justify probability of truth.

3. **One semantic call versus decomposed specialists and reviewers**: six earlier real-Qwen source tasks had direct completed outputs costing **5,593 total tokens / 20.874 seconds**, versus **5,600 tokens / 21.827 seconds for a proposed selector's first stage alone**, with zero corresponding completed selector→answer chains. Recent external published SWE-bench/Terminal-Bench source reanalysis, hash-pinned in `ORACLE_FREE_AGENT_ESCALATION_FINDINGS_2026-10-26.md`, measured independently graded *full* agent workflow outcomes and harmful right-to-wrong replacements under nonoracle triggers, but not on the installed SWAAG Qwen GPUs or with actual per-instance tokens/queue/VRAM. The current policy should retain **one capable initial user-facing model call** and escalate consequential work only with actual source/effect evidence and idempotent receipts, not model votes.

4. **Syntactic auxiliary training**: source-reviewed published studies show task-specific perplexity or syntax improvements with some regressions. No matched initial weights/training FLOPs/data experiment on the installed Qwen models has been run. This retrieval-only experiment has **zero training-time language-model auxiliary interventions** and cannot address that hypothesis. A syntax prompt is not an auxiliary training loss.

## New external corpus and what its independent grades actually mean

This is **BEIR's preprocessed NFCorpus**, *not the native original NFCorpus release* and not a SciFact repeat. Source archive already on Nitro private scratch before this round: `/data/tmp/agent-model-independent-qrels-20261025/nfcorpus.zip`, SHA-256 `efe5be03f8c5b86a5870102d0599d227c8c6e2484328e68c6522560385671b0b`. All five corpus/query/train/dev/test ZIP member SHA-256s are pinned in protocol and tested. The BEIR source contains **3,633 medical text documents**, **3,237 source queries**, **323 original test query IDs**, **12,334 test query/document annotations**. Test query IDs are disjoint from training and development query IDs; source documents/topics can overlap across splits. Test labels consist of **11,758** weaker grade `1` and **576** stronger grade `2` instances. There are **119 queries containing any stronger source citation**, **106** containing both explicit grades, **204** with no stronger annotation and **13** with no lower-grade annotation. All 323 queries were scored; none dropped because it lacked high-grade positives.

**Original-source metadata reconciliation discovered after the frozen run:** Boteva et al.'s *native* NFCorpus 2016 test set has **325 queries**, about **5,371 documents** and **15,820 query-document relevance relationships** according to the original dataset catalog (https://semproc.cl.uni-heidelberg.de/statnlpgroup/nfcorpus/ and https://ir-datasets.com/nfcorpus.html). Its three levels relate to topic links, indirect links, and strongest direct citations; the native test qrel counts are **3,486 level-one topic links, 11,758 level-two indirect links, 576 level-three direct citations**. The BEIR-preprocessed source's **12,334 = 15,820 − 3,486** test relationships, with **11,758 lower and 576 stronger** grades, are numerically consistent with dropping the weakest native links and renumbering the others, but **no row-by-row original-vs-BEIR reconciliation has been performed**. Report the relation only as *count-consistent*, not a verified direct original-label transform. The BEIR source card: https://huggingface.co/datasets/BeIR/nfcorpus ; BEIR source dataset ID and preprocessing lineage: https://github.com/beir-cellar/beir . The native release metadata describes automatically derived relevance labels from NutritionFacts article citation links. These are **source-specific editorial citation linkage labels, not independently human adjudicated semantic entailment, factual truth, clinical validity or SWAAG user/worker action gold**. No native full-corpus metric can be inferred from the preprocessed source subset.

Crucially, **there are no BEIR test grade-zero or explicit irrelevant judgments in this ZIP**. Grade 1 is relevant (weaker original citation), not a verified negative semantic outcome; unjudged source documents are unknown. The usual whole-corpus nDCG scoring convention assigns **zero gain to unknown** for ranking metric only, not to assert real-world irrelevance. On 106 queries with both explicit grades, a grade-1 document serves as a **relative negative for the narrower hypothesis “strongest/direct rather than weaker/indirect citation”**. This is not an independently verified false medical statement. All returned source labels and IDs were scored from immutable `qrels/test.tsv`, not from model opinions or an assistant-generated gold file.

## Actual frozen cross-genre run: same 323 queries and 3,633 documents

Methods were prespecified: Unicode lowercase lexical tokenization with no stemming/stopword list, BM25 k1=1.2,b=.75, TF-IDF 1–2 grams with `sublinear_tf` and max 100,000 features, and unsupervised reciprocal-rank fusion RRF(k=60) of the two full-corpus ranks. Negative controls: per-query source-text-blind SHA256 document order and **query-blind training-citation popularity**, using only the archive's original train qrels. No test qrel information, original answer label, document ID prefix `MED-` or role-coded source ID was used to rank text-based candidates. Ties resolved by original document ID. No Qwen or other LLM was executed.

| Fixed method | 323-query macro graded nDCG@10 (95% descriptive query-bootstrap interval) | 119-query stronger-citation recall@10 | 106-query stronger-vs-weaker AUC |
| --- | ---: | ---: | ---: |
| Fixed query/document hash, text blind | 0.0131 [0.0084, 0.0179] | 0.0050 | 0.4862 |
| Training-citation popularity, query blind | 0.0636 [0.0432, 0.0881] | 0.0028 | 0.3152 |
| **BM25** | **0.3081 [0.2762, 0.3426]** | **0.3356 [0.2725, 0.4019]** | **0.7253 [0.6755, 0.7687]** |
| TF-IDF | 0.2946 [0.2614, 0.3271] | 0.3250 | 0.7201 |
| BM25 + TF-IDF RRF | 0.3054 [0.2714, 0.3391] | 0.3379 | 0.7231 |

**Preregistered acceptance: BM25 passed**, with all-query nDCG differences **+0.2950 versus fixed hash** [paired bootstrap 0.2588, 0.3292] and **+0.2445 versus train citation popularity** [0.2027, 0.2881]. Both exceed the prespecified ≥0.03 difference and strictly positive lower-bound requirements. However **neither TF-IDF nor RRF qualified to replace BM25**: TF-IDF minus BM25 was **−0.01344** [−0.02517, −0.00353]; RRF minus BM25 was **−0.00268** [−0.00975, +0.00466], neither reaching the required ≥0.02 gain. RRF's tiny stronger-recall point advantage was **+0.00227** at ten docs with CI [−0.02098,+0.02887]; that is not decisive. The indexed information itself supplies the ranking; a dedicated semantic LLM relevance selector call has no demonstrated benefit for this benchmark.

**Hard, source-verified misses remain:** BM25 recovered **150 of the 576** original strongest-grade citation relationships in its first ten results, leaving **426 known strongest-grade docs** outside top ten. A different *macro*, equal-weighted per-query recall@10 is 0.3356 across 119 queries; it differs from aggregate 150/576 because each query has a different number of strongest-grade docs. **40 of 119** queries with a strongest-grade document had *zero* in their top ten. Increasing BM25 retrieval to top 20 raises macro stronger-grade recall to **0.4327 [0.3641,0.4979]** but still misses many. A further **2,530 of 3,230** BM25 top-ten source slots were **unjudged**, and cannot be called false positives. Compared with hash and citation-popularity controls, these results support lexical source retrieval, **not source completeness** and certainly not factual answer correctness. The full post-result case-ID miss ledger, graded preference inversions and source-version caveat are in `evidence/nfcorpus-cross-genre/postresult_source_version_and_missed_strong_qrels_v1.json`; no copied query/medical abstract text in Git.

The **relative strong-vs-weak preference** signal on 106 explicitly mixed-grade queries was BM25 macro AUC 0.7253 versus hash 0.4862 and global citation popularity 0.3152. This is a real externally recorded difference in *citation-strength ordering*, not a contradiction detector. The 1,000-query bootstrap gives descriptive intervals conditional on this annotation process and 323 test queries. It does **not** account for shared medical subjects, repeated documents across queries, or original citation-link annotation uncertainty. No claim of independent patient-level or user-level statistical significance follows.

## Cost, selection bias, and deployment decision

Actual Nitro process wall time for original hash validation, corpus loading, both index builds, 323 full-corpus rankings per method, evaluation and paired query bootstraps was **107.39 seconds**, with peak process RSS **379,052 KiB**. The BM25 index took **4.18 s**, TF-IDF **10.68 s**; the BM25 method's ranking CPU/wall sum for 323 queries was **7.42 s** versus **25.61 s** for TF-IDF. An RRF pipeline requires both source-ranking methods plus additional merging cost (**7.21 s** measured in this run). These are an isolated research process under shared Nitro load, not stable deployed per-request latency or Qwen tokens; source whitespace length is a proxy, not model tokenizer cost. The Qwen inference count, direct-to-specialist comparison count and production GPU cost introduced by **this** experiment are **zero**.

**Deployment choice only for this exact narrow retrieval subproblem:** If a purely lexical source-navigation fallback is required, retain the simple **BM25 over the available full original text** rather than adding a separate TF-IDF selector or RRF based on these heldout results. Neither lexical retrieval nor citation-link labels can verify a scientific conclusion, a completed SWAAG worker action, a personal user priority or a superseded instruction. Keep exact original task/source identity and verified-effect receipts. A retrieval hit may propose what to read; **independent source checking** must establish whether it truly answers the current task. This round does not authorize any production config or model change, and no shared GPU service was disturbed.
