# Round-seven frozen cross-genre retrieval protocol — BEFORE outcome computation

**Owner's original topic**: Task/consumer-conditioned relevance; numeric vs categorical model scores; direct vs multi-call specialist/reviewer cost and exact final correctness; training-time grammar auxiliary. This new study examines **only external source-document ranking under a different genre**, a necessary but insufficient component of exact task relevance. It does **not** rate user-versus-worker SWAAG messages, evaluate Qwen, measure reviewer correctness, or train grammar loss. No previous denied multi-call or source transport operations may be repeated.

**Source/gold status, audited before methods**: NFCorpus 3,633 source docs; 3,237 original queries; 323 **test query IDs disjoint from both train and dev query IDs**. Original test labels are 12,334 query/document judgments: 11,758 weaker grade `1`, **576** stronger grade `2`, and **no explicit grade-zero/irrelevant judgments**. A total of **119/323 test queries** have >=1 grade-2 doc; 106 have both grade-1 and grade-2 docs; 204 have only lower grades; 13 only grade-2. Labels derive from the NFCorpus citation/relevance construction, **NOT independent blind human-reviewed semantic entailment gold**; score 1 is still relevant, not factually false or universally irrelevant. Unjudged corpus docs are *unknown*, not verified negatives. Training relevance judgments are allowed only for one explicitly query-blind document-popularity control; test labels are NEVER used to select/rank documents, fit weights or tune thresholds.

**Fixed retrieval setup**, all cases same exact original test queries and all full 3,633 original docs. Query text exactly `queries.jsonl` text; document text `title + space + text`, preserving the source content but not injecting source IDs into textual scoring. Tokenization BM25: Unicode lowercase `(?u)\\b\\w+\\b`, no stemming/stopword list; BM25 k1=1.2,b=0.75; IDF `log(1+(N-df+0.5)/(df+0.5))`; default score zero on absent terms. TF-IDF: sklearn `TfidfVectorizer(lowercase=True, token_pattern=r'(?u)\\b\\w+\\b', ngram_range=(1,2), min_df=1, max_features=100000, sublinear_tf=True,norm='l2')`, fit on corpus **only**; query vectors via transform; no qrel information. RRF(k=60) of BM25 and TF-IDF full-corpus ranks, one lexical fusion with no tuned weights, 2 ranking calculations. Negative control 1: fixed SHA256 `(seed=20261026,query ID,doc ID)` ranking, no source text. Negative control 2: global train-set citation-count ranking **without reading the query**, ties by document ID; unlike the hash control this uses previous train qrels, but not test labels. All ties resolved by original document ID lexicographic ascending. **No LLM calls in any arm.** Costs include lexical index construction, ranking wall time and CPU memory; no GPU, Qwen tokens, reviewer latency, quantization or complete task effects.

**Separate main and diagnostic scoring**:
1. The *main conventional benchmark metric* is all-323-query macro `nDCG@10` with graded gain `2**original_qrel_grade - 1` (1->1, 2->3), unknown unjudged records assigned 0 **only by the retrieval benchmark convention**. This does **not** imply a human-verified negative or factual irrelevance. Report original unknown top-10 count for every method.
2. On all 119 queries with >=1 strong grade-2 doc, macro `strong_grade2_recall@10` and `@20` where numerator is retrieved source docs explicitly graded `2`, denominator is **all** explicitly grade-2 qrels for that query. Missing positives are genuine citation-derived strong-graded misses; retrieved unjudged items cannot be scored as semantic false positives.
3. On exactly 106 **explicitly judged both-grade** test queries, per-query AUC for ranking grade-2 docs above grade-1 docs *within the annotated candidate subset*. Grade-1 is a negative **only to 'stronger grade-2' preference**, not to relevance or science truth. Macro AUC gives each query equal weight; also report pair-weighted micro AUC and preference-inversion rates over explicitly judged grade1×grade2 pairs. The judged-candidate-only analysis has privileged access for scoring; it is NOT a deployable retriever.
4. Report answer *citation provenance* at doc-ID level, top-10 source IDs, qrel grades or `unjudged` (no source text), exact source hashes and corpus/query count; user-facing truthful statement distinguishes ranked candidates from a verified final scientific answer.

**Confidence and acceptance rule, frozen before scoring.** Bootstrap **1,000 query-ID resamples** with fixed seed `20261026`, separately over the 323 all-test queries, 119 strong-grade queries, and 106 both-grade queries, retaining per-query paired algorithm outcomes. These intervals reflect query-cluster variation only, not human-label uncertainty, document/topic independence, a new general domain or true clinical safety. BM25 earns **cross-genre positive retrieval evidence** only if `(BM25 nDCG@10 − hash-control nDCG@10) >= 0.03` and the paired 95% interval lower bound is above zero, *and* `(BM25 − train-popularity) >= 0.03` with its paired lower bound above zero. A candidate TF-IDF or RRF **replaces** BM25 only if it improves all-test nDCG@10 by >=0.02 and has a paired bootstrap 95% lower bound >0, **and** it does not decrease macro strong-grade recall@10 (point estimate) by >0.02. Otherwise retain the lexically simplest BM25 as the provisional retrieval control only; even passing these conditions does NOT establish trustworthy automatic role-specific relevance or a Qwen winner. Report all algorithms and negative outcomes; do not adjust thresholds after outcomes. Heldout means source test query IDs were not in training; this particular NFCorpus archive was already downloaded earlier but no scored NFCorpus outcomes appear in the SWAAG relevance research worktree to date. Cross-genre source from SciFact claims to nutrition informational queries, **not** a same-label/same-task metric transfer; never pool sentence-rationale recall with document-level nDCG or proclaim Qwen generalization.

**Expected limitations**: Query/document labels rely on original citation/link relevance rather than independent entailment; test queries may share topics/docs with train although query IDs are disjoint; 119 strongly graded queries provide valid strong-grade recall only within their recorded pool. 323 is the max query count, not 12,334 independent queries; a given document can recur. Runtime benchmark may be CPU load dependent and rerunning lexical ranking differs from CPU training and real Qwen latency. Any unexpected schema/short query/missing doc must be recorded; no silent drop. No production code changes, no new Calendar task, no additional model service or denied effect.
